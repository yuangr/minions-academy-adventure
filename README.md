# 🍌 小黄人学院大冒险 (Minions Academy Adventure)

> 💡 **创意与制作背景 (Project Story)**：  
> **本项目由我的女儿自己设计，自主提出游戏玩法灵感与全套趣味设定（包括小黄人特工、放屁枪/极度冷冻炮等军械武器、欢乐岛群岛恶人闯关大地图等），全程借助先进 AI 编程工具与大模型人机协作、端到端自动化生成全部前端代码、界面设计与全科情境化百题题库！**  
> 专为低年级小学生量身打造的全科情境化闯关学习网页游戏，包含伴读发音、错题档案、抗挫保护、护眼提醒与多特工独立存档。  
> 📌 **学段与题库说明**：**当前题库精编收录小学二年级上册（苏教版数学、统编版语文、译林版英语）的核心考点内容，暂未扩展其他年级题库和更高难度。**

🎮 **在线试玩体验**：[https://yuangr.github.io/minions-academy-adventure/](https://yuangr.github.io/minions-academy-adventure/)  
*(纯前端静态构建，无需下载安装，支持电脑、iPad 平板、手机浏览器直接开玩！)*

## 🌟 核心特色与玩法

1. **🏝️ 欢乐岛群岛闯关大地图**
   - 包含 5 座恶人主题岛屿：矢量数数沙洲、马乔熔岩岩礁、斯嘉丽城堡崖、巴萨扎算盘屿、六天王金香蕉巅峰；
   - 严格顺序闯关与防跳关机制，浮动悬索木桥串联。
2. **📖 百题全科情境化精编题库 (100 道)**
   - **数学 (45%)**：覆盖苏教版二年级乘除法、算盘认知、三位数读写、元角分换算与有余数除法；
   - **语文 (40%)**：覆盖统编版识字《场景歌》《树之歌》《拍手歌》、部首查字法、经典寓言与动物高频成语；
   - **英语 (15%)**：覆盖译林版核心日常交际、家庭称谓、宠物外貌与点餐礼仪；
   - **防死记硬背**：每关动态随机全量打乱题目出题顺序，且选项 A/B/C/D 实时乱序。
3. **🕶️ 四大特工独立档案与军械库**
   - 凯文、斯图尔特、鲍勃、奥托四位特工拥有独立隔离的关卡进度、金币储备与已购武器装备；
   - 特工平底锅、双重激光枪、超级放屁枪、极度冷冻炮、鲨鱼火箭炮等酷炫武器，支持局内快速切换出击。
4. **💡 智能名师辅导与护眼关爱**
   - 答错即刻弹出名师考点精解与点拨，自动录入【错题档案馆】；
   - 纯前端 Web Speech API 智能语音伴读，不依赖外部付费接口；
   - 20 分钟智能防沉迷护眼提醒机制。

## 🚀 本地运行

纯静态网页架构，无需任何编译或构建工具：
```bash
python3 -m http.server 8000
```
浏览器访问 [http://localhost:8000/](http://localhost:8000/) 即可畅玩！
